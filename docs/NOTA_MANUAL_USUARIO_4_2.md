# Nota sobre el manual de usuario anterior

Los archivos `Manual_Usuario_UMG_Plan.docx` y `.pdf` describen la mayor parte del sistema previo a la versión 4.2. Para el cambio de contraseña **ya no se utiliza un código temporal visible**: ahora se solicita el cambio y el Administrador principal lo autoriza o deniega. También se incorporaron roles personalizados. Consulta la guía vigente `GUIA_CAMBIO_CONTRASENA_Y_ROLES.md`.
